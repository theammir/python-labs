# Основи розробки програмного забезпечення мовою програмування Python

## Лабораторна робота №4

### Загальне завдання

Написати програму, яка реалізує функцію для обчислення за індивідуальним
варіантом. Функцію необхідно викликати для кількох різних значень та вивести
результати на екран.

### Індивідуальні завдання (варіант 9)

**9)** Написати функцію для переведення дюймів у сантиметри.

### Посилання на код

**https://github.com/theammir/python-labs/blob/master/lab4/main.py**

### Висновок

Познайомився з синтаксисом визначення функцій у Python, підказками типів (type
hints), частково -- вбудованою бібліотекою `typing`. Реалізував функцію для
конвертації довільних цілих або дробових дійсних (а також, за бажання,
комплексних) чисел з дюймів у сантиметри. Дослідив фізичний і математичний
зміст комплексної довжини об'єктів у математичній моделі Всесвіту. Познайомився
зі спеціальною змінною `__name__`, що набуває імені поточного модуля під час
виконання, або значення `"__main__"` за умови, що цей модуль є точкою входу
програми.
