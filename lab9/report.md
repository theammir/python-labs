# Основи розробки програмного забезпечення мовою програмування Python

## Лабораторна робота №9

### Загальне завдання

Написати програму, яка:

- вводить початкові дані (з файлу або з клавіатури);
- формує результат з використанням регулярних виразів;
- виводить результат на екран або зберігає у файл.

### Індивідуальні завдання (варіант 9)

**9)** Створити програму для перевірки, чи є рядок валідною IP-адресою.

### Посилання на код

**https://github.com/theammir/python-labs/blob/master/lab9/main.py**

### Висновок

Написав регулярний вираз, що коректно перевіряє рядок на відповідність формату
IPv4 адреси: 4 октети, 0-255 кожен, розділених крапками, без зайвих нулів. Хоча
у вимогах до роботи не був чітко прописаний конкретний стандарт IP, програма не
працює для перевірки адрес формату IPv6.
