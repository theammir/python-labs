# Основи розробки програмного забезпечення мовою програмування Python

## Лабораторна робота №5

### Загальне завдання

Написати програму, яка зчитує дані з текстового файлу та записує їх у новий
файл, виконуючи певні перетворення (наприклад, переведення всіх літер у нижній
регістр).

### Індивідуальні завдання (варіант 9)

**9)** Видалити всі порожні рядки з файлу.

### Посилання на код

**https://github.com/theammir/python-labs/blob/master/lab5/main.py**

### Висновок

Познайомився з вбудованою функцією `open` для відкриття файлів у Python.
Навчився перевіряти наявність довільних файлів на диску за їхнім шляхом;
зчитувати, записувати зміст файлів, модифікувати існуючий.
