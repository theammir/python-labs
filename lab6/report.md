# Основи розробки програмного забезпечення мовою програмування Python

## Лабораторна робота №6

### Загальне завдання

1. Встановити необхідні бібліотеки (openpyxl, pandas).
1. Створити структури даних у Python для роботи з файлами: словники,
   списки.
1. Виконати завдання з JSON:
   − зчитати дані з JSON-файлу;
   − обробити дані (додати, змінити, видалити записи);
   − записати змінені дані у новий JSON-файл.
1. Виконати завдання з CSV:
   − зчитати дані з CSV-файлу у список або DataFrame;
   − змінити дані, додати або видалити рядки;
   − зберегти результат у новий CSV-файл.
1. Виконати завдання з Excel:
   − зчитати дані з Excel-файлу у DataFrame;
   − виконати обробку даних (фільтрація, сортування);
   − записати оброблені дані у новий Excel-файл.

### Індивідуальні завдання (варіант 9)

**9)** Розробити програму для конвертації даних з формату CSV у JSON і
збереження результату в JSON-файл.

### Висновок

Познайомився з бібліотекою `json`, її методами `load(s)`/`dump(s)`; а також
бібліотекою `csv`, класом `DictReader`. Розробив програму для зчитування та
парсингу CSV-файлів, конвертації деяких значень рядків у відповідні типи
Python, що існують у форматі JSON.
